# 🌡️ 식품산업 MLOps 모션 스튜디오

**QA/QC · 생산기술 · R&D · HACCP 실무자를 위한 인터랙티브 MLOps 교육 웹앱**

> 🔗 라이브 데모: **https://zizla.github.io/MLOps/**

노트북에서 96% 정확도를 자랑하던 AI 모델이 실제 식품 공장 라인에 들어가면 왜 무너지는지,
그리고 그 간극을 메우는 **MLOps(Machine Learning Operations)** 를 6개 모듈의 애니메이션·시뮬레이션으로 직접 눌러 보며 익히는 단일 HTML 교육 앱입니다.

코딩 경험이 없는 식품산업 종사자·비전공자를 기준으로 설계했습니다. 설치도, 로그인도, 별도 서버도 필요 없습니다.

## 누구를 위한 자료인가

| 대상 | 활용 방법 |
| --- | --- |
| 식품 공장 QA/QC·품질보증 담당자 | 데이터 검증(Pandera)·드리프트 감시가 현장에서 왜 필요한지 1시간 안에 체감 |
| 생산기술·스마트공장 추진 담당자 | PoC 범위, 도입 순서, 설비 예지보전 시나리오를 로드맵 생성기로 정리 |
| R&D·제품개발 연구원 | 실험 추적(MLflow)·모델 레지스트리 개념을 연구노트 비유로 이해 |
| 대학·기업 교육 강사 | 강의 중 시연용. 인터넷 브라우저만 있으면 바로 재생 |
| AI 입문자·비전공자 | MLOps 전체 그림을 6단계로 훑는 오리엔테이션 자료 |

## 6개 모듈 구성

1. **Module 1 · 왜 MLOps인가?** — 실험실 모델 vs 공장 운영
   「신제품 시제품 레시피 vs 대량생산 HACCP 표준공정」 비유로 시작해, 30일 공장 투입 시뮬레이션에서 일반 ML 모델과 MLOps 모델의 성능 격차가 벌어지는 과정을 그래프로 확인합니다.

2. **Module 2 · 데이터 검증 게이트웨이** (Pandera · DVC 개념)
   살균온도·pH·수분함량·미생물 라벨을 슬라이더로 조작해 스키마 검증 게이트에 데이터를 투입합니다. 정상 데이터는 **DVC 버전(로트 번호)** 으로 등록되어 학습 파이프라인으로, `-999°C` 센서 결측·화씨(°F) 단위 혼용·정답 라벨 누락 같은 불량 데이터는 **자동 차단**되어 격리함으로 분기되는 모션을 보여 줍니다.

3. **Module 3 · 실험 추적 & 모델 레지스트리** (MLflow 개념)
   알고리즘을 골라 실험을 돌리고 F1 점수를 기록·비교한 뒤, 우수 모델을 시생산(Staging) → 본생산(Production)으로 승격하고 문제가 생기면 **긴급 롤백**하는 흐름을 체험합니다.

4. **Module 4 · 패키징 & 배포 방식** (Docker · FastAPI)
   Docker 없이 배포할 때 터지는 환경 충돌(내 PC·공장 엣지·본사 클라우드)과 컨테이너 밀폐용기 패키징의 차이를 비교하고, **실시간 API vs 배치 예측** 두 서빙 패턴의 지연·비용 차이를 토글하며 봅니다.

5. **Module 5 · 운영 모니터링 & 드리프트 경보** (Evidently · 재학습 루프)
   계절 원물 변화·설비 노후화로 입력 분포가 밀리는 **Data Drift**를 PSI 지표로 감지하고, 임계치 초과 시 자동 재학습 파이프라인이 가동되어 신규 모델로 교체되는 과정을 시뮬레이션합니다.

6. **Module 6 · 실무 적용 설계기 & 확인 퀴즈**
   관심 적용 분야(HACCP CCP 이탈 예측 / 비전 이물·포장 불량 검사 / 원료·배합 품질 예측 / 설비 예지보전)와 현재 데이터 수준(종이 일지·엑셀 / MES·ERP / 실시간 IoT·PLC)을 고르면 **단계별 MLOps 도입 로드맵**을 생성해 복사할 수 있고, 현장 사례 기반 **5문항 퀴즈**로 마무리합니다.

## 실행 방법

```bash
# 1) 그냥 열기
#    index.html 을 브라우저로 연다 (외부 라이브러리·빌드 과정 없음)

# 2) 로컬 서버로 열기
python3 -m http.server 8000
# → http://localhost:8000
```

- **의존성 없음**: 순수 HTML + CSS + Vanilla JavaScript(Canvas/SVG). CDN도 쓰지 않으므로 오프라인 강의장에서도 동작합니다.
- **모바일 지원**: 반응형 레이아웃, 고해상도(Retina) 캔버스 대응.
- **키보드 접근성**: `Esc` 키로 학습 자료 서랍 닫기, 각 모듈 상단 탭으로 이동.
- 모듈을 전환하면 이전 모듈의 알림(토스트)은 자동으로 정리됩니다.

## 저장소 구성

```
MLOps/
├── index.html   # 앱 전체 (UI·스타일·시뮬레이션 로직 단일 파일)
```

`main` 브랜치와 `gh-pages` 브랜치의 `index.html` 은 동일한 내용이며, GitHub Pages는 `gh-pages` 로 배포됩니다.

## ⚠️ 데이터 고지

앱에 등장하는 살균 온도, pH, 수분 함량, 미생물 검사값, 센서 수치, 모델 성능(F1)은 모두 **교육용 가상 예시**입니다. 실제 공정 기준(HACCP CCP 한계기준, 사내 규격)과는 다르므로 현업 적용 시 반드시 자사 기준·법규를 확인하세요.
