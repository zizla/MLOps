Module 1 · 핵심 개념 체감

왜 MLOps인가? — 실험실 모델(ML) vs 공장 운영(MLOps)

노트북에서 만든 96% 정확도 모델이 실제 식품 공장에 투입되었을 때 벌어지는 차이를 30일 시뮬레이션으로 확인합니다.

🧪

1분 현장 비유 — 신제품 시제품 레시피 vs 대량생산 HACCP 표준공정

Module 2 · 데이터 품질 방어선

데이터 검증 게이트웨이 (DVC · Pandera 개념)

살균 공정 및 원료 입고 데이터가 AI 학습에 들어가기 전, 불량·오류 데이터를 자동으로 차단하는 스키마 검증 게이트를 체험합니다.

🛡️

1분 현장 비유 — 원료 입고 검수(IQC) & 금속검출기

썩은 원료나 이물이 섞인 원료를 생산 라인에 넣으면 전체 로트가 폐기되듯, 오류 센서값(-999°C)이나 단위 혼용(°F)이 AI 학습에 들어가면 모델이 망가집니다. Pandera(데이터 검수 기준서)가 불량 데이터를 입구에서 자동 차단하고, DVC가 통과된 정상 데이터에 로트 번호(버전)를 부여합니다.

Module 3 · 실험 기록 및 버전 운영

실험 추적 & 모델 레지스트리 (MLflow 개념)

수십 번의 모델 실험 결과를 엑셀이나 파일명(최종_진짜최종.pkl) 대신 체계적으로 기록하고, 안전하게 공장 라인에 승격·롤백합니다.

📓

1분 현장 비유 — R&D 배합 연구노트(실험 추적) & 표준배합서 승인대장(레지스트리)

배합비 테스트 결과를 모두 기록해 비교하는 것이 실험 추적(Experiment Tracking)이고, 우수한 레시피를 시생산(Staging) 거쳐 본생산(Production)으로 승격하며, 문제 발생 시 즉시 이전 배합으로 되돌리는(Rollback) 시스템이 모델 레지스트리입니다.

RUN-001 · 로지스틱 회귀 (F1: 0.842) Production 운영 중
이전 버전: 없음

📋 MLflow 실험 로그 & 레지스트리 테이블

🔍 핵심 용어 툴팁

MLflow (실험 추적 도구): 모델 학습 시 사용한 하이퍼파라미터, 데이터 버전, F1-Score 등의 성능 지표를 자동으로 표에 기록하고 비교해 주는 대표 오픈소스 도구입니다.
Module 4 · 현장 배포와 서빙

패키징 & 배포 방식 (Docker · FastAPI · 실시간 vs 배치)

환경 차이로 인한 배포 오류를 막는 컨테이너(Docker) 개념과, 식품 공장의 두 가지 서빙 방식(실시간 API vs 배치)을 모션으로 비교합니다.

🍱

1분 현장 비유 — 표준 규격 밀폐용기(Docker) & 즉석 조리(실시간) vs 새벽 일괄배송(배치)

"내 노트북에선 잘 됐는데 공장 PC에선 에러나요"를 막기 위해 코드·파이썬·라이브러리를 통째로 밀봉한 것이 Docker 컨테이너입니다. 또한 컨베이어 벨트 위 이물을 0.02초 만에 잡아내는 것은 실시간 API, 매일 아침 원료 성적서(COA) 100건을 한 번에 분석하는 것은 배치 예측입니다.

📦 시각화 1. Docker 컨테이너 (식품 밀폐용기) 배포 비교

위 두 버튼을 번갈아 눌러 환경 충돌 에러와 Docker 밀폐용기 패키징의 차이를 확인해 보세요.

⚡ 시각화 2. 서빙 패턴 선택 (실시간 API vs 배치 예측)

현장 적용: 고속 컨베이어 벨트 이물·포장 불량 비전 검사 (POST /api/v1/predict)
응답속도: 18 ms
현장 적용: 매일 오전 06:00 원료 성적서(COA) · 유통기한 안정성 일괄 예측 리포트 생성
대기 중 (원료 COA 120건 대기) 0%
원료 로트 ID 품목명 수분 / 산가 예측 유통기한 안정성 조치 권고
[오전 06:00 배치 작업 실행] 버튼을 누르면 일괄 예측 리포트가 생성됩니다.

🔍 핵심 용어 툴팁

Docker (컨테이너): AI 코드와 실행에 필요한 파이썬·라이브러리를 하나의 표준 상자(이미지)에 담아 어떤 컴퓨터에서도 똑같이 실행되게 만드는 패키징 기술입니다.
Module 5 · 운영 감시와 자동 복구

운영 모니터링 & 드리프트 경보 (Evidently · 재학습 루프)

계절 변화나 설비 노후화로 입력 데이터 분포가 밀려날 때(Data Drift), 이를 지표로 감지하고 자동 재학습을 가동하는 과정을 체험합니다.

📡

1분 현장 비유 — HACCP CCP 관리한계 이탈 경보 & 자동 개선조치

여름철 원유·원물 수분이 올라가면 과거 겨울 데이터로 학습한 AI는 판단이 흐려집니다. Evidently가 입력 분포 변화(PSI / KS)를 실시간 감시하다 한계치(0.20)를 넘으면 즉시 경보를 울리고, 최신 데이터로 모델을 자동 재학습해 교체합니다.

우리 공장·연구소의 현재 수준에 맞는 단계별 MLOps 도입 로드맵을 자동 생성하고, 현장 사례 퀴즈 5문항으로 핵심을 정리합니다.

🗺️

1분 현장 비유 — 스마트공장도 '기초 위생(선행요건) → HACCP → 자동화' 순서로!
